# Criterios de Portfolio

Esta nota resume os criterios usados antes da implementacao.

## O que um projeto precisa provar

1. Consegue resolver um problema real.
2. Tem produto navegavel, nao apenas codigo solto.
3. Mostra dominio de Git, README, scripts e organizacao.
4. Tem testes e uma forma objetiva de verificar qualidade.
5. Explica decisoes tecnicas e tradeoffs.
6. Tem escopo pequeno o suficiente para ficar completo.
7. Conecta a historia profissional da pessoa com a stack desejada.

## Como isso foi aplicado

- Tema escolhido: service desk operacional, conectado a tarefas administrativas, controle de documentos, cadastros e automacao.
- Stack escolhida: React, TypeScript, Express e Zod.
- Qualidade escolhida: testes, CI, README e docs.
- Tradeoff escolhido: JSON local agora; banco real depois.
