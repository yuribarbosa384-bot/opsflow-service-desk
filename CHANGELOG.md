# Changelog

All notable changes to OpsFlow Administrativo are documented here.

## [0.1.1] - 2026-06-09

### Changed

- Updated development dependencies through Dependabot maintenance PRs.
- Simplified the CI test script to avoid redundant npm argument forwarding warnings.

## [0.1.0] - 2026-06-09

### Added

- Full-stack operations dashboard with React, TypeScript, Express, SQLite, and shared domain rules.
- Risk scoring for administrative tasks based on due date, priority, owner load, category bottleneck, and waiting state.
- Kanban, operational queue, filters, task detail panel, comments, audit history, CSV export, and public demo data.
- Automated quality workflow with typecheck, tests, GitHub Pages deploy, CodeQL, Dependabot, security policy, and contribution templates.
- Public case study and screenshots connected to the developer portfolio.

### Notes

- This is the main portfolio project because it connects directly to administrative/backoffice workflow experience.
